A deterministic program that draws a broadsheet front page summing up the world news of Thursday, 26 November 2026 - the Houthi strike claim on the Ras Tanura refinery, Trump tariffs, NATO's eastern flank, Ukraine, Egypt, space and work - as a single 1024x1024 PNG. Pure Python standard library: the program runs twice and writes the same bytes both times.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
